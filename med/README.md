# NEET PG Cutoff Finder

A lightweight branch lookup for NEET PG cutoff ranges. Search a specialty, choose a suggestion, and view available 2024–2025 ranks by category along with 20k to 29k rank band allotted college lists.

## Run locally

From this folder, start a local server:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). No build step or package installation is required.

## Categories

Available cutoff groups include GM, 2A / 2AG / OBC, and ME. Some years or categories may not have values. Verify cutoff information with official KEA notices before making admission decisions.
